# Экран — сайт и мобильное приложение для билета с видом из зала

Демо-сайт для выбора фильма, кресла и ракурса в 3D. Афиша взята с [Киностар · Грозный Молл](https://kinostar-groznymall.com/) на **7 ноября 2026 года**: 16 фильмов и мультфильмов. Каждый открывается по своему адресу `/film/ks-<id>` и содержит собственный выбор сеанса, места, вид из кресла и обзор зала.

## Запуск

```bash
python3 server.py
```

Откройте <http://127.0.0.1:8000/>. Другой порт: `PORT=8080 python3 server.py`. Нужен Python 3.9+; сторонние пакеты не требуются. SQLite создаётся в `data/cinema.sqlite3`. Уже оформленные демо-билеты и тестовые аккаунты сохраняются при перезапуске.

## Мобильное приложение

Та же версия сайта работает как устанавливаемое веб-приложение (PWA) на Android и iPhone: отдельная иконка, экран приложения без адресной строки, нижняя навигация, афиша, выбор места, 3D, регистрация, тестовая оплата и личные билеты. На Android откройте сайт по **HTTPS** и нажмите «Установить приложение» или выберите установку в меню браузера. На iPhone откройте сайт в Safari и выберите «Поделиться» → «На экран Домой». Установить приложение на телефон с `127.0.0.1` нельзя: сначала разверните сервер на публичном HTTPS-адресе. По локальной сети мобильный интерфейс можно посмотреть в браузере с `HOST=0.0.0.0 python3 server.py`, но установка PWA требует HTTPS.

`web/manifest.webmanifest`, `web/service-worker.js` и `web/icons/` отвечают за установку и оформление приложения. Сервис-воркер кеширует только оболочку; расписание, аккаунт, оплата и билеты всегда запрашиваются с сервера. Для работы покупки нужен интернет.

## Что работает

- Главный экран с озвученным роликом. Воспроизведение и звук останавливаются, когда ролик выходит из области видимости. Если браузер блокирует автоматический звук, его можно включить кнопкой.
- Афиша из 16 постеров с поиском и фильтром фильмов и мультфильмов. На главной странице нет выбора места: он находится внутри страницы конкретного фильма.
- Редакционный блок «История вечера» выделяет один фильм крупным постером и ведёт прямо к выбору места.
- Для 12 фильмов 3D-экран воспроизводит трейлер, опубликованный в афише кинотеатра. Видео проходит через сервер сайта, чтобы браузер мог использовать кадры как текстуру WebGL. У четырёх фильмов источник не даёт ссылки на трейлер; для них на экране показан постер этого фильма и недоступна кнопка звука. Интерфейс прямо сообщает об этом.
- Схема зала, рекомендации мест, вид из выбранного кресла, обзор всего зала, переход между креслами и полноэкранный просмотр. Зрители вокруг выбранного места, кресла и акустические панели показаны в 3D. Звук трейлера идёт от двух виртуальных источников по краям экрана; его направление и громкость зависят от положения выбранного кресла.
- Для плавного 3D одинаковые детали кресел рисуются группами, подробные модели людей используются рядом с выбранным местом, а дальние ряды показаны облегчёнными фигурами. Разрешение WebGL ограничено, освещение использует меньше источников, а движение камеры сглаживается между событиями мыши и пальца через `requestAnimationFrame`.
- Переключаемая «Карта ракурса» подсвечивает свободные кресла по углу к экрану и дистанции. После выбора места появляется ориентировочная оценка обзора. Расчёт относится только к демонстрационной 3D-схеме.
- Тестовая регистрация и вход с хешированием пароля; сеанс хранится в HttpOnly cookie. Подтверждение почты для демо не требуется. Билеты аккаунта доступны на разных устройствах, подключённых к одному серверу.
- Тестовая платёжка на сайте и в мобильном приложении: место удерживается 10 минут, успешная или отклонённая оплата имитируется, после успеха выдаётся билет. Запись в SQLite атомарная, повторное подтверждение не выдаёт второй билет. Личный список билетов, печать и экспорт в календарь сохранены.

Для успешного теста используйте **4242 4242 4242 4242**, для отклонения — **4000 0000 0000 0002**. Эти номера вымышлены; настоящие карты вводить не нужно. Деньги не списываются и платёжный провайдер не подключён. Для публичного развёртывания включите HTTPS и `COOKIE_SECURE=1`.

**Билеты на этом сайте демонстрационные и не действуют в кинотеатре.** Схема зала и цены вымышлены. Время сеансов 7 ноября взято из снимка афиши; на следующие дни оно повторяется только для демонстрации интерфейса. Для реальной продажи нужны официальный API расписания, данные залов, подтверждение брони и платёжная система.

## Данные

`kinostar_catalog.json` хранит снимок афиши, описания, адреса постеров, трейлеров и время сеансов. Локальные постеры лежат в `web/media/posters/`. `server.py` добавляет эти фильмы в SQLite и отдаёт `/api/catalog`, `/api/shows/<id>`, `/api/trailers/<id>.mp4`, `/api/auth/*`, `/api/payments/*`, `/api/me/tickets`, `/api/tickets/<token>` и `/api/health`. Старый прямой `/api/orders` закрыт: билет выдаётся после тестовой оплаты. `web/app.js` управляет страницами, регистрацией и покупкой, `web/cinema3d.js` — 3D-сценой.

Three.js включён локально под MIT. Модели зрителей взяты из [Innerscene 3D Parts Library](https://www.innerscene.com/tools/library/3d-parts/avery-riley-morgan-rowan-and-nora-3d-person-audience-row-of--da50868b) под CC0. Сайт загружает облегчённый `web/models/audience-near.glb` (8,6 МБ вместо 30,3 МБ); исходник оставлен для воспроизводимой сборки через `scripts/compact_audience.py`. Постеры и трейлеры принадлежат правообладателям и используются здесь в демонстрационном прототипе по ссылкам из афиши кинотеатра.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Откройте афишу → фильм → сеанс → свободное место → «Вид с места». Сравните крайнее и центральное кресло, включите звук, откройте полный экран, затем зарегистрируйтесь и оплатите тестовой картой 4242. Откройте «Мои билеты», выйдите и войдите снова: билет должен сохраниться. Для проверки отклонения используйте 4000. Для проверки отсутствующего трейлера откройте «Кит: Во тьме глубин (2026)».
